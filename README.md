# LLMs-from-scratch-practice

Hands-on implementation and experimentation with LLM fundamentals.

This repository contains my practice and experiments based on
Sebastian Raschka's *Build a Large Language Model (From Scratch)*.

## Topics

- Tokenization
- Byte Pair Encoding (BPE)
- Data sampling with a sliding window
- Token and positional embeddings
